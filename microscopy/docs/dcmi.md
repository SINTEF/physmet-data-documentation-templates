# Core Metadata

The Dublin Core Metadata Element Set (DCMES), also known as Simple Dublin Core,
standardizes descriptive metadata. Simple Dublin Core consists of 15 elements
designed to describe any type of resource. It is an internationally recognized
standard (ISO 15836; ANSI/NISO Z39.85) used widely for repository
interoperability. DCMI defines Simple Dublin Core as the use of these 15 elements without qualifiers, forming a minimal, portable metadata schema.

# The 15 Core Elements

- Title – The name given to the resource.
- Creator – Person or entity primarily responsible for creating the resource.
- Subject – Keywords or classification terms describing the topic.
- Description – A summary or abstract of the resource.
- Publisher – Entity responsible for making the resource available.
- Contributor – Additional individuals or organizations contributing to the 
  content.
- Date – A relevant point in the resource's lifecycle (e.g., creation, 
  publication).
- Type – Nature or genre (e.g., Image, Dataset).
- Format – Technical format (e.g., TIFF, JPEG, CSV; MIME types optional).
- Identifier – Unique reference (e.g., DOI, internal ID, filename).
- Source – A related resource from which this one is derived.
- Language – ISO language code (e.g., en, fr).
- Relation – Links to related resources.
- Coverage – Spatial or temporal scope (e.g., "microscopy region A3", 
  "2025–2026").
- Rights – Terms of use, copyright, or access restrictions.
