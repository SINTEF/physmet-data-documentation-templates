# physmet data documentation templates

## Description

The objective of this repository is to share the templates and recommended folder structures to
store data in the frame of the SFI PhysMet.

Each type of measurement of simulation has its own folder providing the templates.
The template folder also includes example of files to be filled as well as references files to
be copied as-is (for example a list of available equipment).

## Installation and use

Just clone the repo

The copy the modified template folder in your sharepoint site.
